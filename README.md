# MarkPDF

> **AI出力のコピペ & 画像貼り付けから即座に美しい A4 PDF を作成できる、ブラウザ完結型の Markdown エディタ**

MarkPDF は、ChatGPT や Claude 等の生成AIから出力されたテキストや表、スクリーンショット画像を貼り付け、ワンクリックで印刷・PDF保存ができる軽量 Web アプリケーションです。

サーバーへのデータ送信は一切行われず、すべての処理（パース、画像最適化、サニタイズ、PDFレンダリング）が**ブラウザ内（クライアントサイド）のみで完結**します。

---

## 主な特徴

- 🔒 **100% クライアントサイド動作（安全・セキュア）**
  - 入力テキストや貼り付けた画像は外部サーバーへ一切送信されません。機密情報や社内データも安心して整形・PDF化できます。
  - CDN 版 **DOMPurify** による厳格な XSS サニタイズを実施済み。
- 🖼️ **スマート画像貼り付け & IndexedDB キャッシュ**
  - クリップボードからの直接貼り付け（`Ctrl + V`）やドラッグ＆ドロップに対応。
  - エディタが巨大な Base64 文字列で埋め尽くされないよう、独自の短縮参照タグ（`![図表](image:img_xxx)`）で管理。
  - 1600px を超える高解像度画像は HTML5 Canvas で自動リサイズ・圧縮し、ブラウザの IndexedDB に安全に保存。
- 📑 **「1ページ1画像」自動改ページ制御（@media print 最適化）**
  - 印刷時に画像が巨大化してページを突き抜けないよう、画像最大高さを 120mm に制限。
  - プレビューおよび印刷時に同一ページ内に複数の画像が集中しないよう、2枚目以降の画像の直前に自動改ページ（`break-before: page`）を適用。
- 🎨 **ワンクリック用途別デザインプリセット**
  - **① 論文・学術レポート風**: 明朝体ベース、図表キャプション強調、三線表スタイル
  - **② ビジネス報告書風**: ゴシック体ベース、見出し装飾、アクセントカラー
  - **③ シンプルメモ風**: 等幅フォント混在、無駄のないミニマルレイアウト
- ⚡ **ビルド不要・静的ファイル構成**
  - HTML / CSS / Vanilla JavaScript のみで構成されており、Vercel、GitHub Pages、Cloudflare Pages などにそのままデプロイ可能。

## 使い方

1. **テキストの入力**:
   - 左側のエディタに Markdown 形式でテキストを入力またはペーストします。
   - 上部ツールバーの「📄 サンプル」ボタンでサンプルの読み込みが可能です。
2. **画像の挿入**:
   - スクリーンショットをコピーした状態でエディタ上で `Ctrl + V`、または画像ファイルをエディタ上にドラッグ＆ドロップします。
3. **テーマの選択**:
   - ツールバーのドロップダウンからお好みのスタイルを選択します。
4. **PDF の出力**:
   - 「🖨️ PDF保存 (Ctrl+P)」をクリック、または `Ctrl + P` を押します。
   - ブラウザの印刷ダイアログで「PDF として保存」を選択し、「背景のグラフィック」にチェックを入れて保存します。

## プロジェクト構成

```text
web-markpdf/
├── index.html     # メイン HTML（DOMPurify, marked.js 読み込み、UI構造）
├── style.css      # レスポンシブUI & A4 印刷用 CSS（@media print）
├── app.js         # クライアントサイドロジック（画像圧縮、IndexedDB、自動改ページ）
├── vercel.json    # Vercel 用セキュリティヘッダー設定
└── README.md      # プロジェクトドキュメント
```

## デプロイ方法

### GitHub Pages
1. 本リポジトリをフォークまたはプッシュします。
2. リポジトリの **Settings** > **Pages** で `main` ブランチの `/ (root)` を公開先に指定します。

### Vercel
```bash
npx vercel --prod
```
静的 Web サイトとして即座にデプロイされます。

## セキュリティとプライバシーについて

REA（Reverse Engineer Anything）ツール群を用いた静的セキュリティ監査を実施済みです。
- 外部 API へのデータ送信やテレメトリ通信が存在しないことを確認しています。
- ローカルストレージ（テーマ設定・テキスト）および IndexedDB（画像データ）はお使いのブラウザ内でのみ保持されます。
